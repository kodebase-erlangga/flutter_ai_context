# Contributing

Thanks for your interest in contributing to `flutter_ai_context`.

## Setup

```bash
git clone https://github.com/kodebase-erlangga/flutter_ai_context.git
cd flutter_ai_context
dart pub get
```

## Before submitting

```bash
dart format .
dart analyze
dart test
```

## Adding fixtures

Place test projects under `test/fixtures/` and add integration tests in `test/integration_test.dart`.

## Principles

1. Deterministic over magical
2. Evidence over guessing
3. Graph/model first, Markdown second
4. Local-first, privacy-friendly
